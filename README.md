# Neovim Configuration

A personal Neovim setup built around [packer.nvim](https://github.com/wbthomason/packer.nvim) for plugin management, with LSP, Treesitter, Telescope, and a Git-focused workflow. Leader key is `<Space>`.

## Layout

```
.
├── init.lua                          # Entry point — requires every module below
├── plugin/
│   └── packer_compiled.lua           # Auto-generated by packer (do not edit)
└── lua/tobiadeniji/
    ├── plugins-setup.lua             # Plugin declarations (packer)
    ├── core/
    │   ├── options.lua               # Editor options (numbers, tabs, search…)
    │   ├── keymaps.lua               # All key mappings
    │   └── colorscheme.lua           # Colorscheme selection
    └── plugins/
        ├── alpha.lua                 # Start screen (alpha-nvim)
        ├── autopairs.lua             # Auto-close brackets/quotes/tags
        ├── auto-session.lua          # Session restore
        ├── comment.lua               # gc commenting
        ├── filetypes.lua             # Custom filetype detection
        ├── flash-pane.lua            # Highlight the active pane
        ├── gitblame.lua              # Inline git blame
        ├── gitsigns.lua              # Gutter git signs
        ├── lualine.lua               # Statusline
        ├── notify.lua                # Notification UI
        ├── nvim-cmp.lua              # Autocompletion
        ├── nvim-tree.lua             # File explorer
        ├── telescope.lua             # Fuzzy finder
        ├── terraform-lsp-attach.lua  # Terraform LSP wiring
        ├── toggleterm.lua            # Floating/split terminal
        ├── treesitter.lua            # Syntax/parsing config
        └── lsp/
            ├── lspconfig.lua         # Language server setup
            ├── lspsaga.lua           # Enhanced LSP UI
            ├── mason.lua             # LSP/linter/formatter installer
            └── none-ls.lua           # Formatters & linters
```

`init.lua` loads each of these modules in order; adding a new module means dropping a file under `lua/tobiadeniji/plugins/` and adding a matching `require(...)` line.

## Installation

1. Back up any existing config:
   ```bash
   mv ~/.config/nvim ~/.config/nvim.bak
   ```
2. Clone this repo to `~/.config/nvim`.
3. Start Neovim. On first launch, `plugins-setup.lua` bootstraps packer automatically and clones it into `~/.local/share/nvim/site/pack/packer/start/`.
4. Run `:PackerSync` to install all declared plugins, then restart Neovim.
5. Run `:Mason` to confirm/installl language servers, linters, and formatters.

> Saving `plugins-setup.lua` triggers an autocommand that runs `:PackerSync` automatically.

## Editor options (`core/options.lua`)

| Setting | Value | Notes |
|---|---|---|
| Line numbers | `number` + `relativenumber` | Hybrid numbering |
| Indentation | `tabstop=2`, `shiftwidth=2`, `expandtab` | 2-space soft tabs |
| Wrapping | `wrap=false` | No line wrap |
| Search | `ignorecase` + `smartcase` | Case-smart search |
| Cursor | `cursorline` | Highlight current line |
| Colors | `termguicolors`, `background=dark` | True-color, dark |
| Clipboard | `unnamedplus` | Uses system clipboard |
| Splits | `splitright`, `splitbelow` | New splits open right/below |
| `iskeyword` | appends `-` | Treats hyphenated words as one |

Scrolloff (8 lines) and incremental search are set in `core/keymaps.lua`.

## Key mappings (`core/keymaps.lua`)

Leader is `<Space>`.

### General
| Key | Action |
|---|---|
| `//` (insert) | Exit insert mode |
| `<leader>c` | Clear search highlights |
| `x` | Delete char without yanking |
| `<leader>+` / `<leader>-` | Increment / decrement number |
| `J` (normal) | Join line below (cursor stays put) |
| `J` / `K` (visual) | Move selected block down / up |
| `<CR>` (normal) | Enter insert mode |
| `<Space><Space>` | Enter insert mode |

### Windows, tabs & splits
| Key | Action |
|---|---|
| `<leader>sv` | Split vertically |
| `<leader>sh` | Split horizontally |
| `<leader>se` | Equalize split sizes |
| `<leader>sx` | Close current split |
| `<leader>sm` | Toggle maximize split (vim-maximizer) |
| `<leader>to` | New tab |
| `<leader>tx` | Close tab |
| `<leader>tn` / `<leader>tp` | Next / previous tab |

### Buffers & files
| Key | Action |
|---|---|
| `<leader>w` | Write buffer |
| `<leader>q` | Write all and quit (`:wqa!`) |
| `<leader>aa` | Toggle auto-save |
| `<leader>e` | Toggle file explorer (nvim-tree) |
| `<leader>f` | Focus file explorer |
| `<leader>x` / `<leader>y` | Toggle relative numbers in explorer on / off |

### Telescope
| Key | Action |
|---|---|
| `<leader>ff` | Find files |
| `<leader>fg` | Live grep |
| `<leader>fc` | Grep string under cursor |
| `<leader>fb` | List open buffers |
| `<leader>fh` | Help tags |
| `<leader>n` | Noice message history |

### Git
| Key | Action |
|---|---|
| `<leader>b` | Toggle inline git blame |
| `<leader>gp` | Preview hunk (gitsigns) |
| `<leader>gc` | Git commits (checkout with `<CR>`) |
| `<leader>gfc` | Git commits for current file |
| `<leader>gb` | Git branches |
| `<leader>gs` | Git status with diff preview |

### LSP & tools
| Key | Action |
|---|---|
| `<leader>rs` | Restart LSP server |
| `<C-d>` | Smart scroll in lspsaga windows |
| `<leader>m` | Toggle terminal (toggleterm) |
| `<leader>mm` | Re-init toggleterm |
| `<leader>a` | Open Alpha start screen |
| `<leader>p` | Highlight active pane (FlashPane) |
| `<leader>cc` | Toggle Claude Code |

### Motion (macOS Cmd / Alt)
`<D-Left>`/`<D-Right>` and `<M-Left>`/`<M-Right>` move by word; `<D-Up>`/`<D-Down>` and `<M-Up>`/`<M-Down>` jump by paragraph; `<C-Left>`/`<C-Right>` jump to start/end of line. These work in normal, visual, and insert modes.

## Plugins (`plugins-setup.lua`)

Highlights of what's installed:

- **UI/UX** — `vim-nightfly-guicolors` (colorscheme), `lualine` (statusline), `alpha-nvim` (start screen), `noice` + `nvim-notify` (messages), `indent-blankline`, `dressing.nvim`.
- **Navigation** — `telescope.nvim` (+ fzf-native), `nvim-tree`, `vim-tmux-navigator`, `vim-maximizer`.
- **Editing** — `nvim-autopairs`, `nvim-ts-autotag`, `Comment.nvim`, `vim-surround`, `vim-ReplaceWithRegister`.
- **LSP** — `nvim-lspconfig`, `mason.nvim` (+ mason-lspconfig), `lspsaga.nvim`, `none-ls.nvim` (+ mason-null-ls), `lspkind`, `typescript.nvim`, `gopher.nvim`.
- **Completion** — `nvim-cmp` with `cmp-buffer`, `cmp-path`, `cmp-nvim-lsp`, `cmp_luasnip`; `LuaSnip` + `friendly-snippets`.
- **Treesitter** — `nvim-treesitter` for syntax and parsing.
- **Git** — `gitsigns.nvim`, `git-blame.nvim`.
- **Workflow** — `auto-session`, `auto-save.nvim`, `toggleterm.nvim`, `overseer.nvim`, `vim-helm`, `claude-code.nvim`.

## Common commands

|---|---|
| `:PackerSync` | Install/update/remove plugins to match `plugins-setup.lua` |
| `:PackerStatus` | Show plugin status |
| `:Mason` | Manage LSP servers, linters, formatters |
| `:LspInfo` | Inspect attached language servers |
| `:LspRestart` | Restart language servers (`<leader>rs`) |
| `:Telescope` | Open the Telescope picker menu |
| `:checkhealth` | Diagnose configuration issues |

## Customizing

- **Editor behavior** → `core/options.lua`
- **Key mappings** → `core/keymaps.lua`
- **Colorscheme** → `core/colorscheme.lua`
- **Add a plugin** → declare it in `plugins-setup.lua`, add config under `plugins/`, then `require` it from `init.lua`
- **Language servers** → `plugins/lsp/lspconfig.lua` and `plugins/lsp/mason.lua`
